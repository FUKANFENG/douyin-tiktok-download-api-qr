# Docker 版验证记录

## 采集与发布整合版（2026-10-30）

- 后端单元、回放和所选集成测试共 3,591 项通过；账号服务 36 项测试通过。
- 真实后台浏览器在模拟创作者网站完成视频选择、标题正文填写、单次提交和新作品核对；重复提交、重启结果不确定、登录版本变化和 Cookie 作用域均有回归覆盖。
- 前端类型、lint、双语文案和构建检查通过。浏览器验证了账号确认、取消、防重复提交、结果不确定处理和手机布局。
- 新 Docker 实例完成初始化；启用 sandbox 的容器浏览器用已有抖音登录态成功确认真实创作者账号。
- 现有安装升级后，10 个身份的凭据密文校验值与 4 条下载记录均保持一致，采集接口实际解析成功。
- 本次未发布真实作品。发布适配参考此前已验证的 social-auto-upload 流程；平台审核、额外身份验证和页面变化仍由平台决定。

首次后端测试有三项旧 webhook 测试因隔离网络无法解析测试域名而失败；为测试运行器提供确定的公共测试地址后重跑通过，没有改动产品的 SSRF 检查。新接口的错误断言按现有 DTK 的 HTTP 400 契约修正后通过。

验证日期：2026-10-29。环境：Windows Docker Desktop、Linux/amd64 容器。

## 已验证

- 应用与独立扫码镜像均从本仓库 Dockerfile 构建成功。
- Windows 安装入口在容器内生成配置，重复运行保留原配置。
- 新数据卷安装成功，额外数据库迁移正常执行；六个常驻服务健康，一次性迁移正常退出。
- 首次初始化管理员、登录、未认证拒绝和认证后的扫码桥接正常。
- 非 root、只读文件系统、丢弃全部容器 capabilities 的条件下，Chromium sandbox 正常启动，并从抖音实际取得二维码图片。
- 取消扫码后会话终止；合成测试账号可经扫码服务加密保存、导入身份池，重复导入复用同一身份。
- 重启 API 与扫码容器后，管理员、加密密钥、已保存的测试账号和导入关联仍然有效。
- 单元、回放及所选扫码/身份/备份集成测试共 3,592 项通过；独立扫码服务另有 25 项测试通过。后端格式、lint、类型检查和前端 verify 均通过。
- 发布源文件与当前部署的环境密钥逐项比较，未发现运行凭据；配置、加密记录、数据库及下载文件均不入库。

## 范围

本轮 Docker 验证覆盖真实二维码生成，账号导入和重启验证使用合成凭据；手机扫码确认及真实账号的平台下载由操作者自行完成。未验证 ARM64。

构建访问外部依赖源时曾发生网络超时；验证环境使用了构建代理。代理地址和凭据未写入源码或镜像配置。镜像仍使用官方固定版本来源与锁文件。

CI 的镜像任务会构建本版两个镜像、启动新实例，并实际启动启用 sandbox 的浏览器，防止仅检查浏览器文件是否存在而遗漏启动故障。
