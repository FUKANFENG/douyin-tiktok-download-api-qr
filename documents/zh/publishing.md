# 抖音采集与视频发布

> **[Douyin_TikTok_Download_API](https://github.com/Evil0ctal/Douyin_TikTok_Download_API)**

[English](../en/publishing.md)

控制台新增“发布视频”，与采集共用扫码保存的加密登录状态。管理员选择账号与本地视频，先检查真实创作者昵称和账号编号，再明确确认发布。

完整的操作步骤、任务状态、异常处理、Agent API 和备份更新说明见 [采集与发布使用指南](../qr/PUBLISHING.md)。

发布账号始终固定。结果不确定时不会自动重发；清理本机草稿不会删除平台作品。

正文下方支持搜索并选择最多五个话题，或明确添加自定义话题。账号检查完成后可以确认上传至抖音草稿，获取基于视频画面的原生推荐；推荐不自动选中，也不发布作品。发布前会校验实际话题关联，话题变化后需要重新确认。
