# Security

Do not post cookies, tokens, passwords, setup links, vault keys, or unredacted logs in public issues. Reports about this QR edition belong to this repository, not to the upstream maintainer. Use GitHub private vulnerability reporting when available; otherwise open an issue containing only a request for a private contact channel, without sensitive details.

The default Docker deployment exposes only the authenticated console on loopback. Its QR API is internal and requires a separate bearer token. Back up the configuration and encrypted credential volume together. The Chromium seccomp profile permits user namespaces while retaining the default deny policy.
